### 3. アプリ名の決定

**候補出し:** 40個の候補を6カテゴリで提案

- 色×パズルの直球系
- カラフル・ポップ系
- 3Dポップ・遊び心系
- 和テイスト・日本語系
- ゲーム・ブランド感重視系
- 覚えやすさ最強系

**ユーザーの好みの方向性:** 色×パズルの直球系、ゲーム・ブランド感重視系、覚えやすさ最強系

**選定プロセス:**
1. 「IroDoku」が気に入る → ベースに決定
2. IroDoku派生20候補を追加提案
3. 最終候補: IroDoku（原案）に一本化
4. 表記: **IroDoku**（キャメルケース）に確定
5. → 後にユーザー判断で **IroPre（イロプレ）** に最終変更

**名前の由来:** 色（Iro）+ ナンバープレース（Number Place → Pre）

### 4. PRDレビュー（リードエンジニア指摘事項）

以下7点の指摘を実施:

| # | 指摘 | 対応結果 |
|:--|:--|:--|
| 1 | メモ機能の仕様が未定義 | **P2に移動**（MVPでは不要。色の候補表示は視認性が悪く、コンセプトと合わない） |
| 2 | エラーチェック無制限はバランス懸念 | **スコアペナルティを追加**（各パズル5回、使用ごとに-50pt） |
| 3 | undo機能がP0に入っていない | **P0に追加**（全手戻し対応） |
| 4 | 6×6ブロック形状が曖昧 | **横長（2行×3列）に確定** |
| 5 | SwiftDataモデル定義が不足 | **4モデル定義を追加**（GameProgress, ClearRecord, AchievementRecord, UserSettings） |
| 6 | BGMのスコープ | **P2に移動** |
| 7 | ポーズ中の盤面非表示 | **盤面を非表示にする仕様に確定** |

### 6. エンジニアUI実装レビュー（7つの指摘）

| # | 指摘 | 決定内容 |
|:--|:--|:--|
| 1 | 操作フロー（セル選択 vs 色選択のどちらが先か） | **カラーファースト方式**（先に色を選ぶ → マスをタップ） |
| 2 | 9×9のタップターゲットが44pt未満 | **そのまま**（ハプティクス + ハイライトで補助） |
| 3 | パレット色選択状態のリセットタイミング | **配置後も色を維持**（連続配置モード。同じ色再タップで解除） |
| 4 | undo履歴上限 | **全手戻し対応**（配列で操作履歴保持、メモリコスト軽微） |
| 5 | ダークモード切替時の色変化問題 | **ゲーム中はモード切替ロック**（ホーム/設定でのみ変更可） |
| 6 | 横画面対応 | **ポートレート固定**（将来対応） |
| 7 | チュートリアル再アクセス | **ホーム「遊び方」+ 設定「チュートリアル再表示」** |

### 7. フォント選定

**3案を提示:**

| 案 | 英語 | 日本語 | 結果 |
|:--|:--|:--|:--|
| A | SF Pro Rounded | SF Pro | デザイナー推奨 |
| B | Roboto | Noto Sans JP | ユーザー初期希望 |
| C | SF Pro Rounded | Noto Sans JP | **✅ 採用** |

**決定理由:**
- ユーザーはRoboto + Noto Sans JPを希望
- デザイナーから「RobotoはAndroidっぽい」「iOSではSF Pro系が最適」と指摘
- エンジニアから「Robotoバンドルでアプリサイズ5-10MB増」と指摘
- 折衷案のC案（英語=SF Pro Rounded、日本語=Noto Sans JP）に決定
- Noto Sans JPは3ウェイト（Regular, SemiBold, Bold）で約3MB

## 確定した仕様サマリー

### アプリ基本情報

| 項目 | 内容 |
|:--|:--|
| アプリ名 | IroPre |
| 読み | いろぷれ |
| プラットフォーム | iOS 18+ |
| フレームワーク | SwiftUI（100%ネイティブ） |
| アーキテクチャ | MVVM + Clean Architecture |
| データ永続化 | SwiftData（ローカルのみ） |
| ビジネスモデル | 無料 + 広告（AdMob） |
| 画面回転 | ポートレート固定 |

### ゲーム設計

| 項目 | 内容 |
|:--|:--|
| ルール | 数独ルールを色に置換 |
| 盤面サイズ | 4×4（2×2ブロック）、6×6（2×3横長ブロック）、9×9（3×3ブロック） |
| レベル | 1〜100（4×4: Lv1-20、6×6: Lv21-50、9×9: Lv51-100） |
| カラーパレット | ライト9色 + ダーク9色 = 18色 |
| 操作フロー | カラーファースト（色を選ぶ→マスをタップ） |
| 連続配置 | 配置後も色を維持（再タップで解除） |
| 問題生成 | ハイブリッド（事前500問 + 動的生成） |

### MVP機能（P0）

- ゲームプレイ（色配置）
- レベル選択（1-100）
- カラーパレット（連続配置モード）
- チュートリアル（4ステップ、再アクセス可能）
- ヒント機能（マスヒント3回/エラーチェック5回/ブロックヒント1回）
- エラーチェック（スコアペナルティ付き）
- undo（全手戻し）
- 実績システム
- ダークモード（ゲーム中ロック）
- 色覚アクセシビリティ（パターン/シンボルモード）

### 将来機能（P1-P2）

- P1: タイマー、広告統合
- P2: 統計ダッシュボード、デイリーチャレンジ、メモ機能、BGM

### デザイン

| 項目 | 内容 |
|:--|:--|
| テーマ | 3Dポップ × カラフル |
| アイコン | SF Symbols準拠（絵文字不使用） |
| フォント（英語） | SF Pro Rounded |
| フォント（日本語） | Noto Sans JP (Regular, SemiBold, Bold) |
| ロゴ | 3×3カラーグリッドのオリジナルSVG |
