# IroPre 🎨

> 色で解く、新しい数独体験

IroPreは、数独の数字を「色」に置き換えたiOSパズルゲームアプリです。

## Features

- 4×4 / 6×6 / 9×9 の3種類の盤面
- レベル1〜100の段階的な難易度
- 3Dポップなビジュアル
- 色覚アクセシビリティ対応（パターン / シンボルモード）
- ダークモード対応
- 実績システム

## Tech Stack

- SwiftUI (iOS 18+)
- MVVM + Clean Architecture
- SwiftData
- SF Pro Rounded + Noto Sans JP
